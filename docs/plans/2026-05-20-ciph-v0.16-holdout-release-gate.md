# CIPH v0.16 Holdout Release Gate Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a deterministic holdout-release gate over `EVALUATION.json`.

**Architecture:** `release_holdout.py` validates the search protocol, validates selected frontier candidates, checks release budget, mutates `EVALUATION.json` exactly once, and emits text or HTML evidence. `validate_evaluation.py` is extended to accept and verify post-release state.

**Tech Stack:** Python 3 standard library, `unittest`, JSON, HTML report helpers.

# CIPH v0.19 Score Integrity Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add tamper-evident evaluator artifact hashes for research-grade CIPH scores.

**Architecture:** Evaluator manifests gain optional `integrity` metadata with SHA-256 digests for declared inputs, evidence, and outputs. A standalone validator follows score provenance from `EVALUATION.json` to evaluator manifests and checks the current bytes. Historical runs remain valid unless they invoke the new integrity validator.

**Tech Stack:** Python standard library, `unittest`, existing CIPH HTML report helpers.

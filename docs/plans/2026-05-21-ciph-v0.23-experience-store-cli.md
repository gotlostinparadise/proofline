# CIPH v0.23 Queryable Experience Store CLI Implementation Plan

## Scope

Implement a local, read-only experience-store projection for prior CIPH runs and mirror it into the bundled and installed Proofline skill.

## Steps

1. Add failing tests for indexing run manifests, traces, closeout status, replay receipts, filters, JSON output, HTML output, and CLI argument behavior.
2. Implement `scripts/query_experience_store.py` with deterministic sorting, safe local path handling, and no secret-bearing evidence body serialization.
3. Update README, `harness/CIPH.md`, bundled Proofline skill docs, bundled script assets, and Proofline skill tests.
4. Dogfood the CLI against the current `runs/` directory to generate JSON and HTML query artifacts for v0.23.
5. Sync the installed Proofline skill and verify the installed copy can emit a query report.
6. Run manifest checks, trace lint, generated reports, full unit tests, and `scripts/check_repo.py`; then merge and push.

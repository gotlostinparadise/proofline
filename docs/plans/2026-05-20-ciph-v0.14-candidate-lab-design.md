# CIPH v0.14 Candidate Lab Design

## Goal

Turn the existing candidate scaffold into a Meta-Harness-style candidate lab that preserves enough filesystem evidence for later optimization, ablation, and holdout-safe evaluation.

## Choice

The next slice is candidate-record hardening, not holdout scoring yet. Holdout discipline depends on reliable candidate records: lineage, hypothesis, changed modules, policy/source snapshots, raw trace, artifacts, and validation. Without that substrate, an evaluator would score thin placeholders.

## Candidate Record Shape

Each candidate lives under `runs/<run-id>/candidates/<candidate-id>/` and includes:

```text
score.json
NOTES.md
patch.diff
TRACE.jsonl
policy/
  README.md
source/
  README.md
artifacts/
  .gitkeep
trace/
  prompts.jsonl
  tools.jsonl
  failures.md
```

The legacy `trace/` files remain for compatibility. `TRACE.jsonl` becomes the research trace ledger for candidate-level events.

## Score Contract

`score.json` keeps existing score fields and adds `schema_version`, `hypothesis`, `lineage`, `candidate_trace`, `artifact_paths`, and `mechanism_metrics`. Existing `parent_ids`, `changed_modules`, `search_scores`, `trace_paths`, and `pareto_status` remain so current summaries do not break.

## Validation

Add `scripts/validate_candidate.py` as a deterministic read-only validator. It checks required files, candidate ID consistency, candidate trace linting, declared trace paths, artifact paths, and score shape. It can emit text to stdout or a self-contained HTML report for run evidence.

## Non-Goals

- No model runner or automatic candidate proposer.
- No holdout scoring or split enforcement yet.
- No mutation of candidate scores during validation.
- No provider-specific API integration.

## Success Criteria

- New candidates have full Meta-Harness lab structure.
- Candidate records can be validated independently from the parent manifest.
- Dogfood v0.14 includes a valid candidate and validation report.
- Bundled and installed Proofline assets expose the same candidate lab behavior.

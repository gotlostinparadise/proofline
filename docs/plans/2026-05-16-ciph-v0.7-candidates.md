# CIPH v0.7 Candidate Traces Plan

## Goal

Add candidate trace and scoring scaffolding for future harness optimization.

## Scope

- Add `scripts/init_candidate.py` to create candidate directories, trace files, notes, patch placeholders, and score records.
- Add `scripts/candidate_summary.py` to render a Markdown score table and Pareto frontier status.
- Document the candidate workflow.
- Dogfood with scored `baseline` and `weaker` candidates under `runs/ciph-v0.7-candidates/`.

## Non-Goals

- No automatic benchmark execution.
- No model prompt optimization.
- No automatic score mutation during summary rendering.

## Verification

- Add tests for candidate creation and summary rendering.
- Generate a candidate summary report.
- Run lint, checks, verify, status, and closeout for the v0.7 run.

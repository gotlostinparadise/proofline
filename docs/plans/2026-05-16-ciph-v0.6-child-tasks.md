# CIPH v0.6 Child Tasks Plan

## Goal

Add bounded child-task packet and workspace scaffolding for delegated CIPH work.

## Scope

- Add `scripts/init_child_task.py`.
- Add child task and response templates.
- Create child directories with `TASK.md`, `RESPONSE.md`, `OWNERSHIP.json`, `inputs/`, `scratch/`, and `artifacts/`.
- Document child-task creation in README and harness docs.
- Dogfood the command with `runs/ciph-v0.6-child-tasks/children/docs-worker/`.

## Non-Goals

- No actual sub-agent spawning.
- No automatic merging of child artifacts.
- No concurrent execution.

## Verification

- Add tests for child packet creation, overwrite refusal, unsafe ID rejection, and direct CLI execution.
- Run lint, checks, verify, status, and closeout for the v0.6 run.

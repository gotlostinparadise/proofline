# CIPH v0.17 Holdout Final Comparison Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add deterministic holdout score ingestion and final comparison reporting after holdout release.

**Architecture:** Holdout scores are separate JSON records copied into `runs/<run-id>/holdout_scores/` and linked from `EVALUATION.json`. Validation owns protocol safety, and `final_comparison.py` renders the final search-vs-holdout outcome.

**Tech Stack:** Python standard library, `unittest`, existing CIPH HTML report helpers.

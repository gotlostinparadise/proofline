# CIPH v0.20 Evaluator Replay Readiness Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add metadata-only replay readiness validation for evaluator manifests.

**Architecture:** Evaluator manifests gain an optional `replay` object. A standalone validator follows score provenance from `EVALUATION.json` to evaluator manifests and checks that replay metadata is local, deterministic, and consistent with expected output hashes. Historical runs stay valid unless the new validator is invoked.

**Tech Stack:** Python standard library, `unittest`, existing CIPH HTML report helpers.

# CIPH v0.13 Mechanism Metrics Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add deterministic mechanism metrics over CIPH manifests and trace ledgers.

**Architecture:** Keep metrics as a read-only script over `MANIFEST.json` and `TRACE.jsonl`. The script emits JSON by default and self-contained HTML when requested, then candidate scoring can ingest the JSON without changing trace or manifest authority.

**Tech Stack:** Python 3 standard library, `unittest`, JSONL, HTML report helpers.

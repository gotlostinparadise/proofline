# CIPH v0.8 Repo Gate Plan

## Goal

Replace the long manual development check loop with one deterministic repository health gate.

## Scope

- Add `scripts/check_repo.py`.
- Run unit tests, manifest linting, manifest verification, closeout coverage checks, and optional `git diff --check`.
- Document `python3 scripts/check_repo.py` as the default repo health command.
- Dogfood with `runs/ciph-v0.8-repo-gate/`.

## Non-Goals

- No CI provider configuration.
- No automatic `run_checks.py` execution, because evidence generation should remain explicit.

## Verification

- Add tests for clean repo pass, missing closeout failure, and direct CLI execution.
- Run the gate against this checkout.
- Run lint, checks, verify, status, and closeout for the v0.8 run.

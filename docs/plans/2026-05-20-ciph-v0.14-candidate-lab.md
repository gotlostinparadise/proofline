# CIPH v0.14 Candidate Lab Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Upgrade CIPH candidate records into validated Meta-Harness candidate lab records.

**Architecture:** Keep candidate creation and validation deterministic. `init_candidate.py` creates a richer candidate directory and score contract; `validate_candidate.py` reads those records and emits diagnostics without mutating them. Existing candidate summaries remain backward-compatible.

**Tech Stack:** Python 3 standard library, `unittest`, JSON, JSONL, HTML report helpers.

---

# CIPH v0.4 Manifest Lint Plan

## Goal

Make weak manifests fail early before verification or closeout.

## Scope

Add `scripts/lint_manifest.py` with quality rules that are separate from structural validation:

- Reject placeholder text such as generated template fields.
- Reject deliverables without artifact or evidence paths.
- Warn when required checks do not use `evidence_producer: "run_checks"`.
- Reject required check evidence outside `runs/<task_id>/artifacts/checks/`.
- Warn about duplicate artifact or evidence paths within a single deliverable.

## Repo Migration

Bring existing run manifests into the new evidence convention by moving required check evidence under each run's `artifacts/checks/` directory and regenerating evidence with `scripts/run_checks.py`.

## Verification

- Add focused unit tests for lint rules and direct CLI execution.
- Run lint, run checks, verify, and closeout for the v0.4 dogfood run.
- Run lint and verify against all existing run manifests.

# CIPH v0.3 Run Checks Plan

## Goal

Make CIPH evidence executable instead of only hand-written.

## Scope

Add `scripts/run_checks.py` to read `checks[]` from a manifest, run each required command, and write fresh structured evidence to each check's `evidence` path.

## Evidence Contract

A check can set:

```json
{
  "name": "unit-tests",
  "command": "python3 -m unittest discover",
  "required": true,
  "evidence": "runs/<run-id>/artifacts/checks/unit-tests.txt",
  "evidence_producer": "run_checks"
}
```

When `evidence_producer` is `run_checks`, `verify_manifest.py` must reject missing, malformed, failed, or stale evidence. Stale means the structured evidence does not match the current check name and command.

## Non-Goals

- No scheduler.
- No parallel command execution.
- No timeout policy in v0.3.
- No external service or dependency.

## Verification

- Add unit tests for passing checks, failing checks, stale evidence rejection, and direct CLI execution.
- Dogfood with `runs/ciph-v0.3-run-checks/`.
- Run full unit tests, run checks, manifest validation, and closeout.

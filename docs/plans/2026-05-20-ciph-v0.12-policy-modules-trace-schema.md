### Task 2: Add Trace Schema And Linter

**Files:**
- Create: `scripts/lint_trace.py`
- Test: `tests/test_lint_trace.py`
- Modify: `README.md`

**Step 1: Write failing tests**

Cover valid JSONL, invalid JSON, unknown event type, missing `schema_version`, missing `event_id`, missing `occurred_at`, missing `event_type`, and event-specific required fields.

Minimum event types:

```python
REQUIRED_FIELDS = {
    "stage.started": ["stage"],
    "stage.completed": ["stage", "status"],
    "state.written": ["path"],
    "state.loaded": ["path"],
    "model.call": ["role", "input_ref"],
    "model.result": ["role", "output_ref"],
    "tool.call": ["tool", "command"],
    "tool.result": ["tool", "exit_code"],
    "handoff.created": ["child_id", "task_path"],
    "handoff.returned": ["child_id", "response_path"],
    "handoff.reviewed": ["child_id", "status"],
    "validation.started": ["check_name"],
    "validation.completed": ["check_name", "status", "evidence_path"],
    "candidate.created": ["candidate_id"],
    "candidate.scored": ["candidate_id", "score_path"],
    "failure.classified": ["failure_type"],
    "recovery.attempted": ["strategy", "status"],
    "budget.updated": ["budget_type", "remaining"],
    "closeout.completed": ["status"],
}
```

**Step 2: Run tests to verify they fail**

Run: `python3 -m unittest tests.test_lint_trace`

Expected: FAIL because `scripts/lint_trace.py` does not exist.

**Step 3: Implement minimal linter**

Use `json.loads()` line-by-line. Require `schema_version == "ciph.trace.v1"`, non-empty `event_id`, `occurred_at`, `event_type`, known event type, and event-specific fields.

**Step 4: Add CLI behavior**

Run: `python3 scripts/lint_trace.py runs/<run-id>/TRACE.jsonl --root .`

Expected output for valid files should include `PASS trace <path>`.

**Step 5: Run focused tests**

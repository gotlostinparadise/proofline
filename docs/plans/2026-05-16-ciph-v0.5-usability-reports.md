# CIPH v0.5 Usability Reports Plan

## Goal

Make CIPH easier to operate by writing reusable reports instead of requiring users to copy terminal output.

## Scope

- Add `--output` to `scripts/closeout_check.py`.
- Add `scripts/run_status.py` for a concise Markdown status summary.
- Update README, harness docs, and task template with report commands.
- Dogfood the flow with `runs/ciph-v0.5-usability-reports/`.

## Non-Goals

- No HTML report.
- No persistent database.
- No automatic command execution from the status report.

## Verification

- Add tests for status rendering, status file output, direct CLI execution, and closeout file output.
- Generate `status.md` and `closeout.md` in the v0.5 run.
- Run lint, checks, verify, status, and closeout.

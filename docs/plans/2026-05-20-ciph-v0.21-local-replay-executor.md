# CIPH v0.21 Local Replay Executor Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build an opt-in local executor for evaluator replay commands that enforces no-shell, local-only, argv allowlist, timeout, network isolation, and post-run output hash verification.

**Architecture:** Add `scripts/execute_evaluator_replay.py` beside the v0.20 replay readiness validator. The script reuses readiness validation as its preflight, discovers unique evaluator manifests through score provenance, supports dry-run by default, and executes only with `--execute` plus `--allow-argv0` under Bubblewrap `--unshare-net`.

**Tech Stack:** Python 3 standard library, `unittest`, existing CIPH HTML report helpers, Bubblewrap for local network isolation when execution is requested.

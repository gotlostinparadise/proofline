# CIPH v0.15 Evaluation Protocol Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a deterministic evaluation protocol for search-set versus holdout discipline.

**Architecture:** Store protocol state in `runs/<run-id>/EVALUATION.json`. Validate it with a read-only script that checks baseline, budget, split separation, candidate score paths, frontier release rules, and holdout leakage. Candidate summaries read the protocol when present and display evaluation phase/holdout status.

**Tech Stack:** Python 3 standard library, `unittest`, JSON, HTML report helpers.

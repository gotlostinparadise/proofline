# CIPH v0.2 Init Run Plan

## Goal

Make CIPH usable without manually copying templates.

## Scope

Add a quick-start README and a small initializer command:

```bash
python3 scripts/init_run.py <run-id> --objective "Describe the coding task."
```

The initializer creates:

- `runs/<run-id>/TASK.md`
- `runs/<run-id>/MANIFEST.json`
- `runs/<run-id>/artifacts/.gitkeep`

## Behavior

- Validate run IDs to prevent path traversal and accidental nested paths.
- Refuse to overwrite an existing run unless `--force` is passed.
- Replace `<run-id>` and `<original objective>` placeholders in generated files.
- Stay Python-stdlib-only.

## Verification

- Add unit tests for generated files, overwrite refusal, unsafe run ID rejection, and direct CLI execution.
- Dogfood the command by creating `runs/ciph-v0.2-init-run/`.
- Run full unit tests and both manifest closeout commands.

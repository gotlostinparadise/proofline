# CIPH v0.21 Local Replay Executor Design

## Objective

Add an opt-in local executor for evaluator replay metadata. CIPH v0.20 proves that an evaluator manifest contains enough safe metadata to replay a local command; v0.21 turns that metadata into a bounded execution path without making provider calls or treating replay as automatic.

## Approach

The executor lives in `scripts/execute_evaluator_replay.py`. It first runs the existing replay readiness validator, then discovers evaluator manifests through `EVALUATION.json` score provenance. By default it performs a dry run and reports which evaluator commands would run. Actual execution requires `--execute` plus at least one `--allow-argv0` entry, so arbitrary manifest commands do not run just because they exist.

Executed commands must keep `shell: false`, `external_effect_policy: local-only`, and relative working directories under the repository root. Environment values are never recorded. The runtime environment is rebuilt from manifest `env_allowlist` names only, and reports include only command metadata, exit codes, timing, and output byte counts.

## Network And Effect Boundary

Execution requires Bubblewrap (`bwrap`) and runs commands with `--unshare-net`. If the network sandbox cannot be found, execution fails closed. The executor does not claim to make arbitrary local filesystem writes impossible; it verifies declared output hashes after the command exits and reports mismatches as failures.

## Reports

The tool writes self-contained HTML or text reports with `data-proofline-report="evaluator-replay-execution"`. The report separates dry-run, skipped, passed, and failed evaluator executions. Command stdout and stderr are suppressed to avoid leaking secrets into durable artifacts.

## Non-Goals

- No provider invocation, remote evaluator execution, or API-key handling.
- No new score schema.
- No automatic execution from repository gates unless a run explicitly adds the executor as a check.
- No claim of cryptographic trust; output hashes remain local drift evidence.

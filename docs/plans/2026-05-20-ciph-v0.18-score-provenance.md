# CIPH v0.18 Score Provenance Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add evaluator manifests and score-provenance validation for research-grade score records.

**Architecture:** Score files carry optional `score_provenance` objects. A standalone validator enforces provenance for a run by following `EVALUATION.json` score paths, loading evaluator manifests, and checking local evidence. Existing candidate and final reports display evaluator IDs when present.

**Tech Stack:** Python standard library, `unittest`, existing CIPH HTML report helpers.

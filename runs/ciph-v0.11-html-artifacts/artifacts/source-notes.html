Applicable Lessons

  • HTML is useful when agent output is spatial, comparative, or review-heavy.
  • Plans, status reports, closeouts, candidate comparisons, and code reviews benefit from semantic sections, tables, and visual hierarchy.
  • Self-contained files keep artifacts portable and inspectable without adding a web server.
  • The migration should preserve machine-readable JSON manifests and use HTML for human review surfaces.

Migration Boundary

  • New generated human-facing artifacts should be HTML-first.
  • Historical Markdown runs stay valid and are not rewritten.
  • No remote assets, JavaScript dependency, or framework is needed for this migration.
  • X status pages did not expose tweet text in this environment, so implementation does not depend on inaccessible tweet content.

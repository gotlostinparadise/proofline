CIPH Task

Objective

Implement CIPH v0.23 Queryable Experience Store CLI: add a deterministic read-only command that indexes prior run traces, manifests, deliverables, checks, closeout status, and replay receipt evidence into queryable JSON/HTML reports with docs, Proofline bundle sync, and dogfood evidence.

Acceptance Object

The work is acceptable when scripts/query_experience_store.py emits deterministic JSON and HTML projections over existing CIPH runs, supports status/event/text/replay filters, excludes secret-bearing evidence bodies, is mirrored into bundled and installed Proofline assets, and passes the run manifest checks plus the full repo gate.

Constraints

  • Repository rules: keep run state durable in TASK.html, MANIFEST.json, TRACE.jsonl, plans, evidence files, and generated reports.
  • Files in scope: scripts/, tests/, README.md, harness/CIPH.md, skills/proofline/, and this run directory.
  • Files out of scope: historical run records except as read-only query input.
  • Permissions: no external services or network facts are required.
  • Secrets handling: do not print or serialize environment values, stdout/stderr bodies, headers, tokens, or raw evidence contents.

Volatile Facts To Verify

No external volatile facts are required. This milestone depends on local repository schemas and scripts only.

Policy Modules

Active modules: state.md, context.md, verification.md, recovery.md, delegation.md, candidate-search.md, and stopping.md.

Trace Ledger

Research runs use runs/ciph-v0.23-experience-store-cli/TRACE.jsonl for raw events. Validate it with scripts/lint_trace.py before closeout.

Mechanism Metrics

Research runs can derive mechanism metrics with scripts/trace_metrics.py. Use them to inspect harness behavior; keep manifest validation and closeout evidence as the source of completion truth.

Risks And Blockers

  • The query surface could accidentally become a mutable database; keep it a projection only.
  • Evidence files may contain command output; index paths and metadata only, not raw bodies.
  • Historical run schemas vary; missing optional fields should produce stable defaults instead of crashes.

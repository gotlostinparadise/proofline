Capsule Plan Review Field Test

Objective

Review and harden the Capsule MVP implementation plan, then record whether Proofline catches weak planning evidence before implementation.

Acceptance Object

The work is acceptable when the Capsule MVP implementation plan is reviewed, a concrete hardening issue is recorded, the plan is corrected, and the run renders status and closeout evidence.

Constraints

  • This run reviews and hardens the plan; it must not implement Capsule.
  • Count the catch only if the implementation plan is actually hardened.
  • Do not use optimizer, candidate, evaluation, or replay tooling.
  • Do not expose secrets or environment values in artifacts.

Core Proofline Workflow

Use this path for real scoped work.

  1. Add explicit requirements to this task and MANIFEST.json deliverables.
  2. Add required checks and evidence paths in MANIFEST.json.
  3. Execute checks and write evidence with: 
    python3 scripts/run_checks.py runs/proofline-capsule-plan-review-field-test/MANIFEST.json --root .
  4. Validate manifest contracts: 
    python3 scripts/lint_manifest.py runs/proofline-capsule-plan-review-field-test/MANIFEST.json --root .
python3 scripts/verify_manifest.py runs/proofline-capsule-plan-review-field-test/MANIFEST.json --root .
  5. Render closeout artifacts: 
    python3 scripts/run_status.py runs/proofline-capsule-plan-review-field-test/MANIFEST.json --root . --output runs/proofline-capsule-plan-review-field-test/artifacts/status.html
python3 scripts/closeout_check.py runs/proofline-capsule-plan-review-field-test/MANIFEST.json --root . --output runs/proofline-capsule-plan-review-field-test/artifacts/closeout.html
  6. Run repository gate when the work is complete: 
    python3 scripts/check_repo.py

Policy Modules

List any active harness policy modules from harness/policies/. Policy modules describe strategy; deterministic scripts still own exact validation and scoring.

Trace Ledger

Proofline core runs use runs/proofline-capsule-plan-review-field-test/TRACE.jsonl for raw events. Validate it with scripts/lint_trace.py before closeout.

Mechanism Metrics

Research runs can derive mechanism metrics with scripts/trace_metrics.py. Use them to inspect harness behavior; keep manifest validation and closeout evidence as the source of completion truth.

When Not to Use Proofline

  • One-line typo fixes.
  • Trivial local-only edits with no durable handoff.
  • Throwaway experimentation with no evidence dependency.

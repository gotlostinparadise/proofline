Proofline Field Experiment Final Synthesis

Objective

Finalize the Proofline field experiment with a clear evidence-backed decision and completion audit.

Acceptance Object

The work is acceptable when the field-trials register covers five trials, the final decision is explicit, the unclear-handoff finding is recorded, and status/closeout evidence renders from passing checks.

Constraints

  • Distinguish core Proofline evidence from optimizer-layer evidence.
  • Make the decision understandable without reading the whole chat.
  • Do not use optimizer, candidate, evaluation, or replay tooling.
  • Do not expose secrets or environment values in artifacts.

Core Proofline Workflow

Use this path for real scoped work.

  1. Add explicit requirements to this task and MANIFEST.json deliverables.
  2. Add required checks and evidence paths in MANIFEST.json.
  3. Execute checks and write evidence with: 
    python3 scripts/run_checks.py runs/proofline-field-experiment-final-synthesis/MANIFEST.json --root .
  4. Validate manifest contracts: 
    python3 scripts/lint_manifest.py runs/proofline-field-experiment-final-synthesis/MANIFEST.json --root .
python3 scripts/verify_manifest.py runs/proofline-field-experiment-final-synthesis/MANIFEST.json --root .
  5. Render closeout artifacts: 
    python3 scripts/run_status.py runs/proofline-field-experiment-final-synthesis/MANIFEST.json --root . --output runs/proofline-field-experiment-final-synthesis/artifacts/status.html
python3 scripts/closeout_check.py runs/proofline-field-experiment-final-synthesis/MANIFEST.json --root . --output runs/proofline-field-experiment-final-synthesis/artifacts/closeout.html
  6. Run repository gate when the work is complete: 
    python3 scripts/check_repo.py

Policy Modules

List any active harness policy modules from harness/policies/. Policy modules describe strategy; deterministic scripts still own exact validation and scoring.

Trace Ledger

Proofline core runs use runs/proofline-field-experiment-final-synthesis/TRACE.jsonl for raw events. Validate it with scripts/lint_trace.py before closeout.

Mechanism Metrics

Research runs can derive mechanism metrics with scripts/trace_metrics.py. Use them to inspect harness behavior; keep manifest validation and closeout evidence as the source of completion truth.

When Not to Use Proofline

  • One-line typo fixes.
  • Trivial local-only edits with no durable handoff.
  • Throwaway experimentation with no evidence dependency.

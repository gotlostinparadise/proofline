CIPH Task

Objective

Implement CIPH v0.21 Local Replay Executor: execute approved local evaluator replay commands from metadata-only replay contracts with explicit opt-in, timeout, no shell, local-only effect policy, output hash verification, docs, Proofline bundle sync, and dogfood evidence.

Acceptance Object

Accepted when the local replay executor dry-runs by default, executes only with explicit approval and argv0 allowlisting, uses a Bubblewrap no-network sandbox for execution, verifies declared output hashes, is documented and bundled into Proofline, is dogfooded on a local evaluator, and the repository gate passes.

Constraints

  • Do not execute replay commands by default.
  • Require --execute and an explicit --allow-argv0 match before running any command.
  • Require shell: false, local working directories, and external_effect_policy: local-only.
  • Use a no-network sandbox when executing; fail closed if it is unavailable.
  • Record environment variable names only and suppress command stdout/stderr in durable reports.
  • Mirror workflow changes into bundled and installed Proofline skill assets.

Volatile Facts To Verify

No external volatile facts are required. The slice depends on local CIPH JSON contracts, Python standard-library subprocess/hash behavior, and locally available Bubblewrap execution isolation.

Policy Modules

Active modules: state, context, verification, recovery, delegation, candidate-search, and stopping.

Trace Ledger

Research runs use runs/ciph-v0.21-local-replay-executor/TRACE.jsonl for raw events. Validate it with scripts/lint_trace.py before closeout.

Mechanism Metrics

Research runs can derive mechanism metrics with scripts/trace_metrics.py. Use them to inspect harness behavior; keep manifest validation and closeout evidence as the source of completion truth.

Risks And Blockers

  • Execution must fail closed if network isolation is unavailable.
  • Command output can contain secrets, so reports must store metadata rather than stdout/stderr content.
  • Local replay proves reproducibility of declared local outputs, not trust in the evaluator itself.

Proofline Real-Task Campaign

Objective

Validate whether default Proofline workflows catch concrete issues in 5 real historical repository tasks and record outcomes.

Acceptance Object

Proof of value is each selected task reporting at least one concrete high-severity issue when sampled via history-aware diagnostics.

Constraints

  • No code changes to selected historical runs.
  • Use history-aware diagnostics intentionally with explicit legacy inclusion.
  • No candidate/evaluation/replay layer in this campaign.

CIPH Task

Objective

Implement the research-grade harness optimizer v0.12 foundation: policy modules, trace schema linting, trace-aware run initialization, manifest validation, bundled Proofline asset sync, and documentation.

Acceptance Object

The work is acceptable when the repository contains policy modules, trace schema linting, trace-aware run initialization, manifest validation, mirrored Proofline assets, updated docs, generated status and closeout reports, and runner-produced evidence for all required checks in MANIFEST.json.

Constraints

  • Repository rules: preserve historical run compatibility and follow the v0.12 implementation plan.
  • Files in scope: harness/, scripts/, templates/, tests/, skills/proofline/, README.md, and this run directory.
  • Files out of scope: unrelated repo history and the untracked contributor guide in the original checkout.
  • Permissions: local file edits and local test commands only.
  • Secrets handling: do not print secrets, environment values, tokens, or private headers in evidence.

Volatile Facts To Verify

No external API or pricing facts are required for this milestone. The design baseline came from the arXiv harness papers reviewed before implementation.

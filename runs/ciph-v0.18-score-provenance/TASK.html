CIPH Task

Objective

Implement CIPH v0.18 Score Provenance and Evaluator Manifests: require research-grade score records to reference local evaluator manifests, validate provenance and evidence paths, surface evaluator provenance in reports, sync Proofline assets, and dogfood the workflow.

Acceptance Object

The work is acceptable when research-grade score records can reference evaluator manifests, a validator checks those manifests and evidence paths, candidate and final comparison reports surface evaluator IDs, Proofline bundled assets expose the same workflow, and every required check has generated evidence.

Constraints

  • Repository rules: keep provenance file-backed, deterministic, and local-path verifiable.
  • Files or areas in scope: scripts/, tests/, README.md, harness/, skills/proofline/, and this run directory.
  • Files or areas out of scope: benchmark execution, provider APIs, cryptographic signing, and historical score migration.
  • Permissions: local file edits, local tests, commit/merge/push closeout, and installed Proofline skill sync.
  • Secrets handling: evaluator commands and evidence must not print private payloads, tokens, headers, or environment secrets.

Volatile Facts To Verify

No external API, pricing, product-limit, or provider configuration facts are needed. This milestone uses local JSON contracts and Python standard-library behavior.

Policy Modules

Active modules: state, context, verification, recovery, delegation, candidate-search, and stopping.

Trace Ledger

Research runs use runs/ciph-v0.18-score-provenance/TRACE.jsonl for raw events. Validate it with scripts/lint_trace.py before closeout.

Mechanism Metrics

Research runs can derive mechanism metrics with scripts/trace_metrics.py. Use them to inspect harness behavior; keep manifest validation and closeout evidence as the source of completion truth.

Risks And Blockers

  • Provenance must not be a loose note; it must point to local evaluator manifests and evidence.
  • Historical runs must remain valid unless they explicitly opt into provenance checks.
  • Bundled and installed Proofline assets must stay synchronized.

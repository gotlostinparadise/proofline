Proofline Real-Task Confirmation

Objective

Run the minimal Proofline core workflow on a real maintenance follow-up task and convert the campaign’s real-task findings into a concrete cleanup backlog.

Constraints

  • No candidate/evaluation/replay commands in this run.
  • No behavior changes to historical campaign subjects.
  • No optimizer layer invocation; core workflow only.

Deliverables

  1. Cleanup backlog artifact that captures all 5 confirmed historical campaign hits.
  2. Closeout evidence from manifest lint, trace lint, status render, and closeout render.
  3. Repository gate check for current repo-state readiness.

Required Checks

python3 scripts/run_checks.py runs/proofline-real-task-confirmation/MANIFEST.json --root .
python3 scripts/check_repo.py

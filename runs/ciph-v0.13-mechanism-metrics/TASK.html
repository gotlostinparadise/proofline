CIPH Task

Objective

Implement CIPH v0.13 mechanism metrics: deterministic metrics over MANIFEST.json and TRACE.jsonl, JSON/HTML report output, candidate score integration, documentation, bundled Proofline asset sync, and dogfood closeout evidence.

Acceptance Object

The work is acceptable when mechanism metrics are computed deterministically from MANIFEST.json and TRACE.jsonl, emitted as JSON and HTML, included in candidate summaries, mirrored into bundled Proofline assets, documented, and closed out with runner-produced evidence for all required checks.

Constraints

  • Repository rules: keep metrics read-only and deterministic.
  • Files in scope: scripts/, tests/, templates/, skills/proofline/, docs, and this run directory.
  • Files out of scope: provider APIs, real model runners, and external benchmark execution.
  • Permissions: local file edits and local test commands only.
  • Secrets handling: do not print secrets, environment values, tokens, or private headers in evidence.

Volatile Facts To Verify

List API shapes, CLI flags, config keys, pricing, product limits, schemas, required fields, or other facts that need authoritative sources before implementation depends on them.

Policy Modules

List any active harness policy modules from harness/policies/. Policy modules describe strategy; deterministic scripts still own exact validation and scoring.

Trace Ledger

Research runs use runs/ciph-v0.13-mechanism-metrics/TRACE.jsonl for raw events. Validate it with scripts/lint_trace.py before closeout.

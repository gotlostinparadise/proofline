Proofline Core Validation Run

Objective

Create and validate a minimal Proofline core run proving the default workflow path and repo-gate readiness.

Acceptance Object

Proof of completion is: manifest lint, manifest verification, run checks, rendered status and closeout reports, and a passing repo-gate check.

Constraints

  • No candidate/evaluation/replay workflow is executed in this run.
  • No repository policy changes are made.
  • No secrets are introduced.

Deliverables

  1. Proofline core-first docs are aligned in README, harness/CIPH, skill docs, and templates.
  2. Diagnostics defaults are validated as skip-by-default for legacy runs and explicit when requested.
  3. Closeout artifacts are rendered: artifacts/status.html and artifacts/closeout.html.
  4. Repository gate command passes for this run in context with existing run history.

Required Checks

python3 scripts/run_checks.py runs/proofline-core-validation/MANIFEST.json --root . --include-optional
python3 scripts/verify_manifest.py runs/proofline-core-validation/MANIFEST.json --root .
python3 scripts/check_repo.py --skip-diff-check

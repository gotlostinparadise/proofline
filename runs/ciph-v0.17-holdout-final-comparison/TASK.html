CIPH Task

Objective

Implement CIPH v0.17 Holdout Score Ingestion and Final Comparison: accept holdout scores only after release, validate post-release score paths, produce final comparison reports, sync Proofline assets, and dogfood the workflow.

Acceptance Object

The work is acceptable when holdout scores can be ingested only after holdout_released, EVALUATION.json links a validated canonical holdout score path, final comparison reports rank only scored holdout candidates, bundled Proofline assets expose the same workflow, and every required check has generated evidence.

Constraints

  • Repository rules: keep search scores immutable; holdout scores must be separate canonical files linked from the evaluation protocol.
  • Files or areas in scope: scripts/, tests/, README.md, harness/, skills/proofline/, and this run directory.
  • Files or areas out of scope: benchmark execution, hidden holdout payload storage, provider APIs, and score generation.
  • Permissions: local file edits, local tests, commit/merge/push closeout, and installed Proofline skill sync.
  • Secrets handling: do not print private scenario payloads, tokens, headers, or environment secrets in reports.

Volatile Facts To Verify

No external API, pricing, product-limit, or provider configuration facts are needed. This milestone uses local JSON contracts and Python standard-library behavior.

Policy Modules

Active modules: state, context, verification, recovery, delegation, candidate-search, and stopping.

Trace Ledger

Research runs use runs/ciph-v0.17-holdout-final-comparison/TRACE.jsonl for raw events. Validate it with scripts/lint_trace.py before closeout.

Mechanism Metrics

Research runs can derive mechanism metrics with scripts/trace_metrics.py. Use them to inspect harness behavior; keep manifest validation and closeout evidence as the source of completion truth.

Risks And Blockers

  • Holdout ingestion must be impossible before release.
  • Search scores must remain immutable and distinct from holdout scores.
  • Final comparison must not silently rank unscored candidates as winners.
  • Bundled and installed Proofline assets must stay synchronized.

Capsule MVP Implementation

Objective

Implement the dependency-free Capsule MVP with create, inspect, verify, docs, tests, and field-test evidence.

Acceptance Object

The work is acceptable when capsule.py implements create, inspect, and verify; focused tests pass; docs exist; an example docs-context capsule verifies; and Proofline status/closeout artifacts render from passing checks.

Constraints

  • Dependency-free: use Python standard library only.
  • Capsule owns context packaging, not Proofline task proof.
  • Implement only the reviewed MVP from docs/plans/2026-05-21-capsule-mvp-implementation-plan.md.
  • Keep deterministic --id docs-context behavior.
  • Never print matched secret-like values in warnings or redaction records.

Core Proofline Workflow

Use this path for real scoped work.

  1. Add explicit requirements to this task and MANIFEST.json deliverables.
  2. Add required checks and evidence paths in MANIFEST.json.
  3. Execute checks and write evidence with: 
    python3 scripts/run_checks.py runs/capsule-mvp-implementation/MANIFEST.json --root .
  4. Validate manifest contracts: 
    python3 scripts/lint_manifest.py runs/capsule-mvp-implementation/MANIFEST.json --root .
python3 scripts/verify_manifest.py runs/capsule-mvp-implementation/MANIFEST.json --root .
  5. Render closeout artifacts: 
    python3 scripts/run_status.py runs/capsule-mvp-implementation/MANIFEST.json --root . --output runs/capsule-mvp-implementation/artifacts/status.html
python3 scripts/closeout_check.py runs/capsule-mvp-implementation/MANIFEST.json --root . --output runs/capsule-mvp-implementation/artifacts/closeout.html
  6. Run repository gate when the work is complete: 
    python3 scripts/check_repo.py

Policy Modules

List any active harness policy modules from harness/policies/. Policy modules describe strategy; deterministic scripts still own exact validation and scoring.

Trace Ledger

Proofline core runs use runs/capsule-mvp-implementation/TRACE.jsonl for raw events. Validate it with scripts/lint_trace.py before closeout.

Mechanism Metrics

Research runs can derive mechanism metrics with scripts/trace_metrics.py. Use them to inspect harness behavior; keep manifest validation and closeout evidence as the source of completion truth.

When Not to Use Proofline

  • One-line typo fixes.
  • Trivial local-only edits with no durable handoff.
  • Throwaway experimentation with no evidence dependency.
